En esta entrega se tomaron las siguientes decisiones:

1. En  la portada se optó por ubicar los botones justo al medio, inicio y en toda la página para distribuir de manera homogénea el contenido dentro de ella y que fuera visible, lo cual facilitaría la lectura y no daría espacios a malos entendidos como por ejemplo que el usuario piense que la página no esta cargando. 2. Para la gran mayoría de los campos se decidió hacer la validación de javascript y dejar la del html para mayor seguridad, además en las validaciones se contó en aquellos casos optativos que solo espacios también era valido.

3. Los botones se distinguieron por color según su función, para mayor claridad.

4. Por términos estéticos, las dimensiones indicadas en la tarea se aplicaron solo en el archivo HTML. Sin embargo, para que cada caja de texto fuera del mismo tamaño y se viera más armonioso le asignó el mismo estilo a cada una de las cajas en el css.

5. El formulario se decidio dividirlo en secciones, en caso de ser ncesario utilizar solo algunas parte de ellas, para futuras tareas, quizas esto pueda servir para trabajar por partes de manera más ordenada. 

6. Para el caso de los botones de confirmación de nueva actividad se decidió no agregarle colores pues se vería muy llamativo dado que el fondo del mensaje era verde.

7. Se decidió que la descripción de la actividad debe tener más de tres caracteres, dado que la palabra descriptiva más breve identificada fue "mala", que consta de cuatro letras.

8. Para los campos opcionales se decidió que se validaría que estuviera vacío o que cumpla con ciertas restricciones que deben cumplirse si es que el usuario los decide completar como el caso de descripción.

9. En la página de "Listado de Actividades", se implementó un estilo en el CSS que cambia el color de la fila al pasar el cursor sobre ella, haciendo más evidente que las filas dirigen a una nueva página.

10. En la información del la actividad, al agrandar la imagen, se añadió un fondo oscuro translúcido para centrar la atención en la imagen.

11. Se decidió que los mensajes de validación se mostrarían en verde para los casos de éxito y en rojo para los errores para mayor claridad para un usuario.

12. En el listado no se sabía con certeza si en la descripción de la tarea cuando se decía total de fotos se pedía que se mostraran las mismas fotos o si se pedia el numero de fotos de la actividad.

13. Con los input de las opciones que daban a escoger "Otro", se decidió crear de manera dinámica con javascript un contenedor para lo que se fuera a escribir.
